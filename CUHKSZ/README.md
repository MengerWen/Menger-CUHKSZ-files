每个学期都有 `文件清单.csv`，记录原路径、大小、SHA256 和下载位置。较大单文件的原目录内放有 `.下载.md`；项目数据、模型、运行结果、依赖和 Git 历史保存为 Releases ZIP 附件。

需要资料时，只下载所需文件或 ZIP。每个 ZIP 独立解压，按清单恢复原目录。GitHub 自动生成的 Source code 或 Download ZIP 不包含全部 Releases 附件，请使用学期目录给出的下载链接。

已有的课程目录继续保留。它们原先未按学期分类，目前仍可从本目录直接打开。
