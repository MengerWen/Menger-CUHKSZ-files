### Summary of FiNE Results

| Group | Description | Sample Size ($N$) | Avg. Drop in Fact B Prob. | Conclusion |
| :--- | :--- | :---: | :--- | :--- |
| 🔴 **Set-Poly** | High Overlap (Entangled) | 50 | **88.47%** (Severe / Near-Erasure) | Severe Side Effects |
| 🟢 **Set-Mono** | Low Overlap (Control) | 50 | **77.20%** (Severe) | Control Not Clean (FiNE still unstable) |

> **📉 Metric Note**: **Drop** is computed as $(PB - PB')/PB$. To avoid a few “probability boosts” (negative drops) dominating the mean, we report a **clipped mean** with Drop clipped to $[0, 100]$ and exclude cases with $PB \le 10^{-4}$ (blind/near-blind prompts).

#### A. Entanglement Hurts FiNE (and also Hurts Edit Success)
Under the high-overlap construction (**top-100 neurons**, Jaccard **> 0.1**), FiNE frequently causes extreme collateral damage to Fact B (many “Complete Erasure” rows in the bleed-over table), and it also struggles to achieve the intended edit on Fact A:

* **Set-Poly edit success:** 12% (A\_acc drops from 82% → 12%)
* **Set-Poly locality:** 18% (B\_acc drops from 88% → 10%)

This is consistent with the hypothesis that **polysemantic / shared neurons make neuron-level edits “too sharp,”** so the update that fixes A is likely to cut through B’s retrieval pathway as well.

#### B. Gap Between Sets Still Exists, But Both Are Bad
Comparing the two sets using the same PB-drop metric:

* **Set-Poly:** 88.47% average drop (clipped mean)
* **Set-Mono:** 77.20% average drop (clipped mean)

So **high overlap is worse** (≈ **+11.27 percentage points** more damage), but the low-overlap control set still shows **severe degradation**, suggesting either (i) FiNE hyperparameters are too aggressive for this model/setup, or (ii) the “low overlap” criterion (Jaccard < 0.01 on top-100, layers 10/20) is not sufficient to guarantee functional independence under this evaluation.

#### C. Note on Outliers (Boosts / Blind Spots)
A few cases show “Boost” instead of drop (negative drop%), and some prompts have extremely small PB values (blind-spot behavior). These can make the raw mean misleading (e.g., one very large boost can flip the sign), so the clipped-mean summary above is used as the headline statistic.
